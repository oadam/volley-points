# Où sont tes points à gagner ?

Petit outil d'auto-évaluation pour joueurs et joueuses de volley-ball (6 contre 6, loisir à départemental).

👉 **https://oadam.github.io/volley-points/**

## Ce que ça fait

1. Tu choisis ton poste (polyvalent, réceptionneur-attaquant, central, pointu, passeur, libéro).
2. Tu te situes sur chaque secteur du jeu (service, réception, défense, attaque, etc.) avec un curseur, en choisissant la description qui te ressemble **en match**.
3. Le bilan classe tes axes de progression selon ce qu'ils rapportent, en centièmes de point par set, avec des conseils concrets et un objectif chiffré à surveiller aux prochains matchs.

## Comment c'est calculé

Pour chaque axe, le gain = nombre d'actions jouées par set à ton poste × écart de valeur d'une action entre ton niveau et le suivant. Le tri « Rendement » divise ce gain par un effort relatif, qui dépend de l'axe et augmente avec le niveau.

Ce sont des ordres de grandeur estimés, pas des statistiques mesurées : ils servent à comparer les axes entre eux.

## Technique

Une seule page HTML statique, sans dépendance ni build, publiée avec GitHub Pages.
